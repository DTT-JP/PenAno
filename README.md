# PenAno – LabelMe Annotation Editor

iPad + Apple Pencil 対応のローカルアノテーションエディタです。  
Safari ブラウザ内で LabelMe (JSON) 形式のラベリングデータの **表示・編集・新規作成** を行えます。

> **すべてのデータはローカルで処理されます。画像やJSONがインターネットに送信されることはありません。**

---

## ✨ 機能一覧

### データ読み込み
- **フォルダ読み込み** – 画像 (jpg/jpeg/png/bmp/webp/gif) と対応する LabelMe JSON をまとめて読み込み
- **ZIPファイル読み込み** – ZIP に含まれる画像と JSON を展開して読み込み
- 画像名ベースで自動マッチング（例: `photo.jpg` ↔ `photo.json`）

### アノテーション表示
- ラベリング済みオブジェクトを **縁取り + 半透明塗りつぶし** で表示
- ラベルごとに色を指定可能（localStorageで保存）
- ラベル名をボックス上部に表示

### 編集機能
- **選択モード** – ペンまたはマウスでオブジェクトを選択・移動・リサイズ
  - 8つのハンドル（四隅 + 四辺中央）でサイズ変更
  - ボックス内をドラッグで移動
- **追加モード** – ペンで斜めにドラッグして新しい矩形を作成
  - 追加するラベルをドロップダウンで選択

### ナビゲーション
- 前へ / 次へ ボタンで画像を切り替え
- ファイル名と現在位置（X / Y）を表示
- 全枚数・確認済み・残り枚数のリアルタイム表示

### 確認済みチェック
- 各画像に「確認済み」フラグを設定可能
- フラグは localStorage に自動保存

### 表示倍率
- ＋／− ボタンで拡大縮小
- 数値入力で任意の倍率に変更
- 100% リセットボタン
- iPad の **ピンチジェスチャー** にも対応

### ラベル管理
- 全JSONから自動収集したラベル一覧を表示
- ラベルの追加・削除
- ラベルごとの色をカラーピッカーで変更（localStorageで保存）

### オブジェクトリスト
- 現在の画像内のオブジェクト数を表示
- 個別のオブジェクトを選択・削除

### レイアウト
- **横向き（Landscape）**: 左にサイドバー、右にキャンバス
- **縦向き（Portrait）**: 上にキャンバス、下にサイドバー
- 全画面モード対応

## 🚀 使い方

### 1. ファイルを配信する

静的ファイルなのでローカルWebサーバーで配信します。

**Python の場合:**
```bash
cd PenAno
python -m http.server 8080
```

**Node.js (npx) の場合:**
```bash
cd PenAno
npx serve .
```

### 2. iPadのSafariでアクセス

ブラウザで `http://<PCのIPアドレス>:8080` を開きます。

> 💡 同じWi-Fiネットワーク上であればアクセスできます。

### 3. データを読み込む

- **「フォルダを開く」** をタップして画像とJSONが入ったフォルダを選択
- **「ZIPファイルを開く」** をタップしてZIPファイルを選択

### 4. 編集する

1. 選択モードでオブジェクトをタップして選択
2. ハンドルをドラッグしてリサイズ
3. 追加モードに切り替えてペンで新しいボックスを描画
4. 確認が済んだら「確認済み」ボタンをタップ

## 🔧 LabelMe JSON 形式

本ツールが扱う LabelMe JSON の基本構造:

```json
{
  "version": "5.0.1",
  "flags": {},
  "shapes": [
    {
      "label": "car",
      "points": [[100, 200], [300, 400]],
      "group_id": null,
      "shape_type": "rectangle",
      "flags": {}
    }
  ],
  "imagePath": "photo.jpg",
  "imageData": null,
  "imageHeight": 1080,
  "imageWidth": 1920
}
```

> **注意**: 現在は `shape_type: "rectangle"` のみサポートしています。

## 📋 データ保存について

- **ラベル色**: localStorage に保存（キー: `lme_label_colors`）
- **確認済みフラグ**: localStorage に保存（キー: `lme_confirmed`）
- **編集したアノテーション**: 現在はブラウザメモリ上での編集のみ
  - JSON のエクスポート機能で保存可能

## ⚠️ 動作環境

- **推奨**: iPad + Safari + Apple Pencil
- **対応**: デスクトップブラウザ（Chrome, Firefox, Safari, Edge）でもマウス操作で利用可能
- **必須**: JavaScript 有効、localStorage 利用可能

## 📝 技術メモ

- 外部依存は **JSZip** のみ（ZIP展開用）
- フレームワーク不使用 – Vanilla JavaScript
- 全データはブラウザ内で処理、サーバーへの送信なし
- SVG オーバーレイでアノテーション描画（Canvas上に直接重ねる構造）
- ポインタイベント + タッチイベントの二重バインドで Pencil と指を区別
